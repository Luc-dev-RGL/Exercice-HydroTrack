# Projet Android Jetpack Compose - Suivi d'Hydratation

## 🚀 Comment ouvrir dans Android Studio (2 Méthodes)

### Méthode 1 : Ouvrir directement ce projet décompressé
1. Décompressez le fichier `HydroTrack_Android_Jetpack_Compose.zip`.
2. Lancez **Android Studio**.
3. Cliquez sur **Open** (ou **File > Open**).
4. Sélectionnez le dossier décompressé contenant `build.gradle.kts` et `settings.gradle.kts`.
5. Patientez pendant que Gradle télécharge les dépendances (Sync Gradle).
6. Cliquez sur le bouton vert **Run ▶** (Shift + F10).

### Méthode 2 : Copier dans un nouveau projet Android Studio
Si vous avez déjà un projet ouvert :
1. Dans Android Studio : **File > New > New Project > Empty Activity** (Compose).
2. Nommez le package `com.example.hydrotrack`.
3. Copiez les fichiers du dossier `app/src/main/java/com/example/hydrotrack/` dans votre projet.
4. Lancez l'application !
